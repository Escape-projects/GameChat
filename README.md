# 🎮 GameChat

**Дипломный проект (2025 г.) — Игровой мессенджер**

---

## 📌 О проекте

**GameChat** — это клиент-серверное приложение, разработанное в качестве дипломного проекта. Это текстовый мессенджер, предназначенный для общения игроков в реальном времени. Пользователи могут создавать комнаты по играм, обмениваться личными сообщениями и добавлять друг друга в друзья.

**Основной фокус проекта — бэкенд-разработка:** серверная логика, сетевое взаимодействие, управление состоянием пользователей и работа с базой данных. Проект демонстрирует понимание распределенных систем и клиент-серверной архитектуры.

**Ключевая особенность:** приложение показывает работу **распределенной системы** — серверная программа и клиентские приложения могут находиться на разных компьютерах в разных сетях, обмениваясь данными через интернет по протоколу TCP/IP в реальном времени.

> ⚠️ **Важное примечание:** Проект создавался в сжатые сроки перед защитой диплома и последующей службой в армии. Основной упор был сделан на **сетевую функциональность и бэкенд-логику**, а не на идеальную архитектуру или безопасность.

---

## 🚀 Функциональные возможности

*   **Регистрация и авторизация** пользователей с подтверждением по электронной почте.
*   **Личные сообщения** между пользователями в реальном времени.
*   **Тематические комнаты**, привязанные к играм.
*   **Обмен сообщениями в комнатах** для всех участников.
*   **Система друзей** (отправка и принятие заявок).
*   **Отображение статуса** пользователя (в сети/не в сети).
*   **Администрирование комнат** (выдача бана участникам, смена пароля).
*   **Хранение данных** в Microsoft SQL Server.

## 🏗️ Архитектура

Проект построен по классической **клиент-серверной модели**:

1.  **Клиентское приложение (WinForms):** Предоставляет пользовательский интерфейс.
2.  **Серверная программа (WCF):** Обрабатывает бизнес-логику, управляет подключениями и транслирует сообщения.
3.  **База данных (SQL Server):** Хранит информацию о пользователях, сообщениях, комнатах и друзьях.

Обмен данными между клиентом и сервером происходит по протоколу **TCP/IP** через **WCF-сервисы**, что обеспечивает устойчивую связь для приложений, работающих на удаленных компьютерах.
